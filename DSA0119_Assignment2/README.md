# DSA01 Assignment 2 – Simple C++ Codes

Beginner-friendly programs for Q1–Q7.

## Compile an individual program
```bash
g++ -std=c++17 -Wall -Wextra Q5/Q5_Bus_Tickets.cpp -o q5
```
Windows PowerShell: `./q5.exe`
Linux/macOS: `./q5`

Compile each `.cpp` separately because each has its own `main()`.

## Before submission
- Run each program and save your own output screenshots.
- Write predicted output before running the prediction programs.
- Q6 requires timing tests with `-O0` and `-O2`; record your actual measurements.
- Q7 requires comparison of the original and circular-array versions using the same tests.
- Add name, register number and actual compiler version.
- The report also needs explanations, design decisions, Big-O analysis and evidence. Code alone is not the complete assignment.
